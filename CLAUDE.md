# Instruções para este projeto no Cowork

Leia `AGENTS.md` e `README.md` antes de executar uma tarefa. Para revisar qualquer componente do índice — hoje Button, Hyperlink, Dot, Checkbox e Radio —, localize-o em `components.json`, siga `agents/ds-lead.md` e `agents/component-reviewer.md` e produza o relatório no formato indicado. Os arquivos em `agents/` descrevem papéis e fluxo de trabalho: sua existência não cria agentes separados nem automatiza delegação.

No **Claude Code**, os dois subagentes de projeto estão configurados em `.claude/agents/`; veja `CLAUDE-CODE-AGENTES.md`. Esta configuração não implica que uma sessão do Cowork use subagentes, nem cria um gatilho para rodar sem uma tarefa iniciada.

Se a solicitação for apenas de revisão, não edite arquivos. Use as fontes reais apontadas em `AGENTS.md`; não invente variantes, tokens nem resultados de Figma. Caso não consiga executar `npm run check`, diga isso expressamente.
